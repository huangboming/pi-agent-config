# agy status line

Optional quota status line for agy. It is not installed by the main Pi setup.

From the repository root:

```bash
mkdir -p "$HOME/.gemini/antigravity-cli"
ln -s "$PWD/integrations/agy/statusline.sh" "$HOME/.gemini/antigravity-cli/statusline.sh"
```

Back up or remove an existing destination before creating the symlink.
